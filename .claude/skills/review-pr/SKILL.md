# Ревью изменений WalletAI

Прогнать diff (`git diff` / `git diff --staged`) по чек-листу. Порядок = приоритет.

## 1. Безопасность (блокирует коммит)

- [ ] Нет секретов в diff: API-ключи, пароли, содержимое `.env`/`local.properties`, keystore.
- [ ] Ключ Gemini не попадает в URL как query-параметр и не логируется (заголовок `x-goog-api-key`).
- [ ] В Gemini уходит только агрегированная сводка, не сырая история транзакций и не персональные данные.
- [ ] Нет `Log.*` с финансовыми данными пользователя (суммы допустимы только в debug-логах, и то осознанно).
- [ ] Новые разрешения в манифесте (`RECORD_AUDIO`, `POST_NOTIFICATIONS`…) — обоснованы и запрашиваются в контексте использования, не при старте.
- [ ] Нет новых сетевых вызовов на непроверенные хосты; только HTTPS.

## 2. Целостность данных (блокирует коммит)

- [ ] Изменения Entity сопровождаются `Migration` + bump версии БД; `fallbackToDestructiveMigration` не появился.
- [ ] Деньги — `Money`/`Long` (минорные единицы). Любой новый `Double` для сумм — отклонить.
- [ ] Операции с БД идут через DAO → репозиторий; нет прямого SQL в UI/ViewModel.
- [ ] Удаления данных пользователя — только с подтверждением в UI (или undo через Snackbar).

## 3. Архитектура

- [ ] Бизнес-логика без Android-классов → лежит в `shared/commonMain`, покрыта тестом в `commonTest`.
- [ ] ViewModel не знает про Room/OkHttp — только интерфейсы репозиториев (Koin).
- [ ] Нет магических строк для типов/периодов — enum'ы из `shared/domain`.
- [ ] Нет `!!`, нет `Any` в public API, `val` где возможно.

## 4. Compose/UI

- [ ] Нет тяжёлых вычислений в composition (фильтрация/суммирование — во ViewModel или `remember` с ключами).
- [ ] Состояние экрана — sealed interface; `collectAsStateWithLifecycle()`.
- [ ] Строки UI — на русском; новые экраны не ломают навигацию табов.

## 5. Гигиена

- [ ] Коммит атомарный, сообщение по Conventional Commits на русском (типы/scope — см. AGENTS.md).
- [ ] Нет закомментированного мёртвого кода и неиспользуемых зависимостей.
- [ ] Тесты зелёные: `./gradlew :shared:testDebugUnitTest :app:testDebugUnitTest`.
